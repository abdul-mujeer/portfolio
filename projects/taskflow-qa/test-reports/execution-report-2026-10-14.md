## 8. Known limitations

- No rate limiting / brute-force protection on the auth endpoints (documented, not a seeded bug).
- No 405 handler: unsupported methods on existing paths fall through to the 404 handler (observed in exploratory testing TASK-TC-303).
- Session expiry is 8h and not sliding; no refresh-token or remember-me flow.
- SQLite file database: single-writer; not evaluated for concurrent multi-instance use.
- `npm run lint` covers JavaScript/mjs sources; TypeScript spec files are transpiled by Playwright and not linted (no TypeScript ESLint parser in the dependency allow-list).
- Seeded defects are OFF by default; run `npm run seeded:demo` to see the labelled detection exercise.
